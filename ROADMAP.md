# Film Finder Bot — план работ

Простой телеграм-бот с каталогом фильмов. Node.js.

**Принятые решения:**
- Доставка — **файлом в чат** (`copyMessage` + `protect_content` + автоудаление). Без Mini App, без стриминга, без своего трафика.
- Одно качество на фильм. Без выбора озвучки.
- Монетизация — **подписка** (Telegram Stars) + **гейт на каналы спонсоров** для бесплатного доступа.
- Приоритет — простота. Всё лишнее вынесено в раздел «Потом, если понадобится».

## 2. Как работает выдача фильма

### Ограничения Telegram, из которых всё следует

- Бот **загружает** файл максимум **50 МБ** — для фильма бесполезно.
- Аккаунт пользователя заливает до **2 ГБ** (Premium — **4 ГБ**).
- Бот может **скопировать** уже лежащий в Telegram файл любого размера — заново ничего не грузится.
- `file_id` уникален для каждого бота и может протухнуть. Поэтому основа — `chat_id + message_id`.

### Схема

```
[Ваш аккаунт] --заливает фильм--> [Приватный канал-хранилище]
                                            |
                                   бот админ в канале,
                                   ловит update channel_post
                                            v
                              запоминает chat_id + message_id + file_id
                                            |
                                 вы вводите название,
                                 бот тянет метаданные из TMDB
                                            v
                                     [films в БД]

[Пользователь] --"Смотреть"--> [гвард]
                                  |
                    есть подписка? --да--> выдать
                                  |
                                 нет
                                  v
                    гейт: подпишись на каналы спонсоров
                                  |
                          [✅ Проверить] --> getChatMember по каждому
                                  |
                             все ок --> выдать
                                  v
                    copyMessage(protect_content: true)
                                  v
                 сборщик: удалить сообщение по истечении срока
```

### Почему `copyMessage`, а не `sendVideo(file_id)`

- не зависит от протухания `file_id`;
- копия без пометки «Переслано» — не видно источник;
- поддерживает `protect_content`;
- можно подменить подпись на свою.

Порядок именно такой: **сначала `copyMessage`, при неудаче — `sendVideo(file_id)`.**
`copyMessage` всегда отражает текущее состояние канала, а `file_id` остаётся
запасным путём на случай, если пост в канале удалили: сам файл при этом
никуда не девается.

### Защита

`protect_content: true` (нельзя переслать и сохранить) + автоудаление через N минут + лимит выдач в сутки. От записи экрана не спасает — это фильтр от массового слива.

## 3. Гейт на каналы спонсоров

Ключевая для монетизации механика, разберу отдельно.

### Как проверяется подписка

`getChatMember(channel_id, user_id)` → статус. Пропускаем при `member`, `administrator`, `creator`, а также `restricted` с `is_member: true`. Отклоняем `left` и `kicked`.

### Обязательные условия

1. **Бот должен быть админом в канале спонсора.** Иначе Telegram не отдаст статус участника — проверить нельзя никак. Это условие в договор с партнёром.
2. Приватные каналы работают через invite-ссылку; если у канала включена заявка на вступление, дополнительно ловим `chat_join_request`.

### Практика

- Результат проверки кэшируем в Redis на **5 минут** — иначе на каждом клике летит пачка запросов к API и ловим лимиты.
- Перепроверяем **при каждом запросе фильма**, а не один раз: половина людей отписывается сразу после получения файла.
- Считаем по каждому каналу, сколько человек через него прошло — это отчёт для партнёра и основание для цены за место.
- Ограничение: не больше 3–5 каналов в гейте. Дальше люди просто уходят.
- В том же экране кнопка «Надоело подписываться? Оформить подписку» — основной драйвер продаж.

## 4. Модель данных

```
users                 tg_id (PK), username, first_name, created_at,
                      referrer_id, is_banned, last_seen_at

films                 id, title_ru, title_orig, year, tmdb_id,
                      poster_file_id, description, duration_min, rating,
                      storage_chat_id, storage_message_id,
                      file_id, file_unique_id, file_size,
                      is_published, created_at

genres                id, slug, name_ru
film_genres           film_id, genre_id

plans                 id, code, title, days, price_stars, is_active, sort

subscriptions         id, user_id, plan_id, starts_at, expires_at,
                      source (payment|referral|admin), is_active

payments              id, user_id, plan_id, amount, currency, status,
                      telegram_payment_charge_id UNIQUE,   -- идемпотентность
                      subscription_id, created_at

sponsor_channels      id, title, chat_id, username, invite_link,
                      is_private, is_active, sort,
                      starts_at, ends_at, target_joins, joined_count

sponsor_passes        id, user_id, channel_id, passed_at
                      -- кто через какой канал прошёл: отчёт партнёру

referrals             inviter_id, invited_id, bonus_days, created_at

views                 id, user_id, film_id, created_at
search_queries        id, user_id, query, results_count, created_at
                      -- пустые запросы = список, что заливать дальше

delivered_messages    id, user_id, chat_id, message_id, delete_at
broadcasts            id, text, filter_json, status, sent, failed
```

Поиск: `search_vector tsvector` (GIN) по `title_ru + title_orig`, плюс `pg_trgm` для опечаток («интерстелар» → «Интерстеллар»).

## 7. Потом, если понадобится

Сознательно не делаем в первой версии:

- Mini App с рекламными сетями (Adsgram/Monetag) — можно надстроить поверх, данные не переделывать
- стриминг из Telegram через MTProto
- ЮKassa и оплата рублями (нужно ИП/ООО)
- сериалы: сезоны и серии
- несколько качеств и озвучек
- inline-режим `@bot название`
- избранное, «продолжить просмотр»
- мультиязычность
